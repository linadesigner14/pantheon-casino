# PANTHEON — Casino of the Gods

Concept iGaming landing page with a Greek mythology theme: a Welcome Pack spread over 3 deposits, a Wheel of Fate, a gods games gallery, a VIP path and an FAQ.

- Single-file HTML/CSS/JS, animations with GSAP + ScrollTrigger
- Mobile-first, `prefers-reduced-motion` support, demo registration form
- Illustrations generated with AI (Figma)

> PANTHEON is a fictional brand created for a design portfolio. No real-money gaming; all figures are demo data.

Design & development: **Alina Matronina**, 2026.
